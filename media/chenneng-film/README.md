## 重新生成

安装 Python 的 `Pillow`、`numpy`、`imageio-ffmpeg` 后，在项目根目录运行：

```powershell
python scripts/render-chenneng-film.py
```

默认读取 `C:/Windows/Fonts` 的字体，可通过 `--font-dir` 指定其他目录。先只导出代表画面时，使用 `--frames-only <输出目录>`。图像、配乐和编码均在本地完成；无需 HeyGen 或其他生成额度。

片中数量从 `chenneng/products.js` 读取。产品内容或网站界面更新后，应重新截取对应界面、更新本清单并重新生成视频。所有源图片保留原文件，裁切仅用于视频中的取景与版式。

## 首页播放规则

进入可见区域后尝试静音播放，离屏、切换标签或打开产品详情后暂停。用户手动暂停后不会自动恢复。减少动态效果、省流量或慢速网络偏好采用手动播放；原生控件与页面按钮均可播放、暂停、调整声音。

导出单文件网站时，须同时复制 MP4 和封面到导出文件旁的 `assets/`，它们不会嵌入 HTML。
