## 使用现有 LibTV 结果重新合成

安装 Python 的 `Pillow`、`numpy`、`imageio-ffmpeg` 后，在项目根目录运行：

```powershell
python scripts/compose-chenneng-libtv-film.py
```

默认读取 `sources/libtv-product-v1.mp4` 和 `C:/Windows/Fonts` 字体，可通过 `--video`、`--font-dir` 指定路径。使用 `--output`、`--poster` 可输出预览文件。合成逐帧解码 LibTV 动态视频，并复用旧渲染模块的排版与配乐函数；无需额外生成额度。旧脚本 `render-chenneng-film.py` 仅保留用于追溯原来的纯本地版本，不能替代当前合成命令。

产品内容或网站界面更新后，应重新截取对应界面、更新本清单并重新合成视频。所有源图片与 LibTV 原始视频均保留，避免为字幕、配乐和剪辑修改重复生成。

## 首页播放规则

进入可见区域后尝试静音播放，离屏、切换标签或打开产品详情后暂停。用户手动暂停后不会自动恢复。减少动态效果、省流量或慢速网络偏好采用手动播放；原生控件与页面按钮均可播放、暂停、调整声音。

导出单文件网站时，须同时复制 MP4 和封面到导出文件旁的 `assets/`，它们不会嵌入 HTML。
