# 臣能网站维护

网站入口为 `chenneng/index.html`，无需安装依赖或构建。页面布局、视觉样式和交互分别维护在 `index.html`、`styles.css` 和 `app.js`。

产品数据的唯一维护位置是 `chenneng/products.js`。其中 `CHENNENG_PRODUCTS` 保存 12 款产品的名称、图片、规格、批准或备案号、用法及提示，`CHENNENG_TOPICS` 定义浏览主题。原始资料字段保留；调整展示名称可修改 `displayName`。产品内容应依据实物标签、注册或备案资料及说明书更新。

## 导出原始单文件版本

在项目根目录运行以下命令，替换输出路径即可：

```powershell
node scripts/export-chenneng.mjs "导出目录/臣能产品总览.html"
```

导出工具使用 Node.js 内置模块，将 CSS 内联到页面，将产品数据和交互脚本依次内联到 `body` 末尾，并处理脚本中的结束标签。输出路径相对于当前工作目录，也支持绝对路径；源文件路径依据工具所在位置解析。

导出文件可以直接在浏览器中打开，产品浏览、筛选和详情无需网络服务。本地打开时，分享功能使用 `index.html` 中 canonical 指定的线上地址，避免复制本机文件路径。复制链接等受浏览器权限限制的功能，以页面提示为准。

图片、视频和封面保留 `assets/` 相对路径，未嵌入 HTML。请将完整的 `chenneng/assets/` 目录放到导出 HTML 旁边：

```text
导出目录/
├─ 臣能产品总览.html
└─ assets/
   ├─ 01-tianma.webp
   ├─ …其余产品图片
   ├─ chenneng-brand-film.mp4
   └─ chenneng-brand-film-poster.jpg
```

更新源文件后，重新运行导出命令即可同步单文件版本。不要直接编辑导出 HTML 中的产品数据，以免下次导出时丢失修改。导出工具只写入指定 HTML，不会复制、删除或改变媒体资源。

## 页面状态与交互

- `type`、`topic`、`q` URL 参数保存类别、主题和搜索条件；`product` 打开对应产品详情。
- 产品卡片、搜索索引、数量和详情均由同一份数据生成。搜索支持名称、原料、文号与主题，多个词同时匹配。
- 详情使用原生 `dialog`：支持键盘操作、浏览器前进后退、独立滚动，以及关闭后恢复浏览位置与焦点。
- 320–640px 使用单列图文卡片与底部导航；主题标签只在自身区域横向滚动；大屏使用两列或三列目录。
- `proof` 等原资料字段保留用于追溯，不作为已验证的效果证据展示。产品注意事项中的内部宣传指引不显示给访客。

## 首页宣传片

首页视频由本地文件提供，24 秒，采用 LibTV 生成的产品镜头与本地中文排版、真实网页界面、原创配乐合成。默认静音，在可见区域才尝试播放。访客可以主动暂停或开启配乐；减少动态效果与省流量偏好使用手动播放。

源素材、分镜、重新生成方式见 [宣传片维护说明](../media/chenneng-film/README.md)。更新媒体后应同时更新封面；替换线上同名文件时，还需更新页面的资源版本参数，避免缓存继续提供旧视频。
